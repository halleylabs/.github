Halley is an independent AI lab. We build agents and the tools around them, and we open-source most of what we make.

In 1705 Edmond Halley used first principles to predict that a comet would return in 1758. He didn't live to see it, but it came back on schedule. We try to build the same way: reason it through, ship it, and let it prove itself.

### Projects

| | | |
|---|---|---|
